# 赛场内录视频

RMUC 2026 总决赛（深圳）期间的自瞄相机内录，用来推算场地的光照和表面反射率。结果用于 `../worlds/rmuc_2027_venue.sdf`，方法见 `../docs/venue_lighting.md`。

```
clips/              25 段原始视频（73 MB，来源：飞书 mp4.zip，单个文件最大 15 MB）
SHA256SUMS          clips/ 的校验和
measure_video.py    从 clips/ 重新测量，写出 measurements.json 和 frames/（约 30 秒）
measurements.json   全部测量值；tools/build_venue_lighting.py 直接读取这个文件
frames/             测量用的参考帧：*_linear.png 是原始线性值，*_bright.jpg 只是提亮后方便看
```

校验 `clips/`：

```bash
(cd clips && sha256sum -c ../SHA256SUMS)
```

## 相机

| 项目 | 值 | 来源 |
|---|---|---|
| 型号 | Hikrobot MV-CS016-10UC（Sony IMX273，全局快门） | `rmcs_auto_aim_v2/src/io/capturer/hikcamera.hpp` |
| 分辨率 / 帧率 | 1440 × 1080 / 120 fps | 同上；视频本身也是 120 fps |
| 曝光 / 增益 | 4000 µs / 8 dB，手动固定 | RMCS `rmcs_bringup/config/deformable-infantry-omni.yaml` |
| 内参 | fx 1722.23，fy 1724.88，cx 701.31，cy 564.58 | `rmcs_auto_aim_v2/config/config.yaml` |
| 处理 | Bayer 8 bit → `cv::demosaicing`，无 gamma；白平衡未知 | `capturer.cpp` |
| 编码 | H.264 yuv420p（ffmpeg 8 libx264 转码） | `ffprobe` |

没有 gamma，所以解码后的 8 bit 值（DN）与亮度成线性关系。曝光固定，同一帧里两个表面的 DN 之比就是它们的反照率之比（光照相同时）。这组曝光是 2026-08-10 提交的配置，视频是 08-05 拍的；只用比例，所以曝光是多少不影响结果。

## 注意

- `*_linear.png` 是多帧平均（14-43-37 和 14-41-49 为单帧）。机器人在动，所以贴纸、标线这类测量用的是单帧，见 `measure_video.py`。
- 亮度很低时 H.264 会把暗部压到 0，墙面的值（约 1 DN）只能当作量级。
- 录像是 2026 赛季场地，仿真网格是 2027 版。
